## 🛠️ How to Import XML Presets in Alight Motion:

1. Download the `.xml` file from the [Alight Motion Presets Directory](https://alightmotionsapp.com/alight-motion-preset/).
2. Locate the file in your device's **File Manager** (under `Downloads`).
3. Tap **Share** or **Send** and select **Alight Motion** from the app list.
4. Open Alight Motion, navigate to the **Projects** tab, and your imported preset project will appear automatically at the top.
